# IBM HR Employee Attrition Analysis (Excel)

## 📌 Project Overview

This project analyzes the IBM HR Employee Attrition dataset using Microsoft Excel to answer common HR business questions and generate meaningful business insights.
The project demonstrates Excel skills commonly used by Data Analysts, including data cleaning, structured references, conditional formulas, and business KPI reporting.
This project is currently under development and will be expanded with Pivot Tables, Pivot Charts, and an interactive dashboard.

---

## 📂 Dataset

- IBM HR Employee Attrition Dataset
- 1,470 Employee Records
- 35 Columns

---

## 🎯 Project Objectives

- Analyze employee demographics
- Calculate key HR metrics
- Perform department-wise analysis
- Analyze employee attrition
- Build a structured HR analysis report
- Practice Excel functions used in Data Analytics
